# 开车 / 打车路线与估时

每位朋友的 `travelMode` 可选择 `transit` 或 `driving`；老版本方案未设置时按 `transit` 恢复。朋友的 `enabled` 默认为 `true`，只有本次参加的人参与推荐；关闭后资料仍保存。开车与打车共用道路行驶估时，不模拟叫车等待、找车位或费用。

## 计算与显示

切换到驾车后先立即计算粗估，后台查询高德道路路线，取得结果后重新评分。驾车和地铁按每人的实际估算分钟数进入同一套权重公式，调低权重不会篡改显示的用时。

- 道路估时：高德返回的行车分钟数 + 5 分钟到店步行，标注“高德驾车估时”。
- 粗估：直线距离 × 1.35 / 30 km/h × 60，行车部分至少 1 分钟，再加 5 分钟到店步行。以上是模型假设，并非深圳实测交通速度。
- 缺失、失败或无效的道路结果仅让相应路线回退到粗估，不中断整个推荐。
- 真实道路路线沿返回折线绘制；粗估使用长虚线表示方向，不作为道路导航。每人的颜色保持一致。
- 地铁与驾车步数分别取整后相加，时间线与总用时一致。

## 配置与接口

使用已有的服务端环境变量 `AMAP_WEB_SERVICE_KEY`，需要 **Web 服务** Key 的驾车路径规划权限，无须浏览器 JavaScript API Key。修改环境变量后重新部署或重启开发服务器。

`POST /api/driving` 接受 WGS84 的深圳起点：

```json
{ "origin": { "lng": 114.05, "lat": 22.55 } }
```

服务端固定查询仓库 `districts` 中的候选商圈，不接受客户端指定目的地、上游 URL、API 路径或 Key。成功返回 `routes` 数组，每项包含：

| 字段          | 含义                         |
| ------------- | ---------------------------- |
| `districtId`  | 内置商圈 ID                  |
| `minutes`     | 道路行车分钟数，不含到店步行 |
| `distanceKm`  | 道路距离，公里               |
| `coordinates` | WGS84 道路折线               |

部分成功会返回可用结果；全部失败时返回 `{ "error": { "code": "…", "message": "…" } }`，错误状态区分 400 输入错误、405 方法错误、429 限流、503 配置、504 超时和 502 上游不可用。客户端会标出未取得道路结果的情况，并提供刷新按钮。

服务端请求高德 [`/v3/direction/driving`](https://lbs.amap.com/api/webservice/guide/api/direction)，使用推荐策略 `strategy=10`。`duration` 从秒换成分钟，`distance` 从米换成公里，拼接 `steps[].polyline`。应用内部和底图使用 WGS84，高德使用 GCJ-02，因此请求前转换起终点，响应后反算道路坐标；参考 [高德坐标说明](https://lbs.amap.com/api/webservice/guide/api/convert)。

## 请求量、缓存与隐私

- 至少两人参加时，只有本次参加的驾车朋友触发道路查询；关闭的人不会发起新查询，已开始的客户端请求会取消。仅保存或编辑未参加朋友的资料不触发驾车查询。同一起点去重；客户端最多并行两批起点，服务实例内最多并行三个高德请求。每批最多查询当前 13 个候选商圈。
- 修改姓名、权重和评分策略仅本地重算，不发起新的路线请求。切换方式或更换起点会取消过时的客户端任务；旧位置结果不会用于新位置。
- 完整成功结果在浏览器内存与服务实例内存短暂缓存 5 分钟，缓存大小有限；服务端部分成功短暂缓存 15 秒。刷新可跳过浏览器缓存，但仍可能命中服务端的近期估时。不会后台定时刷路况。
- 起点通过 POST 请求体发送，不包含朋友姓名和地址文字。高德请求仍需要起终点坐标；托管商与地图服务商可能处理请求日志。应用没有行程数据库，不打印 Key 或坐标日志。内存缓存不写磁盘，会随过期、容量淘汰或进程结束释放。
- 当前没有账户或跨实例限流，公共部署需要结合实际流量管理高德接口配额。Key 始终保留在服务端，不进入前端构建或 API 响应。

`bun run dev` 同时运行本地 API 中间件；`bun run preview` 只提供静态页面，驾车会退回粗估。Vercel 部署会将 `api/driving.ts` 识别为 Node.js Function。
